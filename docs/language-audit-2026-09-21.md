# 한글·영어 화면 비교

- 기준: 2026-09-21, 커밋 `4849376`, 로컬 사이트, Edge 헤드리스 브라우저 430×932.
- 공간 콘텐츠 탭은 제외했다. 로그인, AI 3개 화면, 나들이 4개 상태, 내 정보 7개 화면, 택시 설정, 홈, 렌트 3개 단계 등 총 20개 상태를 비교했다.
- 임시 브라우저 프로필과 데모 상태를 사용했다. 한글→영어→한글 전환 전후 DOM의 문구, 버튼 동작 식별자, 입력값, 이미지 경로를 수집했다. 앱 소스는 수정하지 않았다.

## 번역 적용 범위

한글을 포함하는 원문을 중복 제거하고, 영어 전환 후 한글이 남는지 검사했다. 언어 선택기의 `한국어`는 제외했다. 아래 수치는 **번역 적용률**이며 번역 의미의 정확도나 기능 완성도 점수가 아니다. 그림 안의 글자, 접근성 속성은 별도로 확인했으며 이 비율에 포함하지 않았다.

| 영역 | 고유 원문 | 영어에서 한글이 남는 문구 | 번역 적용률 |
| --- | ---: | ---: | ---: |
| 로그인 | 6 | 0 | 100% |
| 홈 일반 문구 | 27 | 0 | 100% |
| 렌트 설정·픽업·오류 | 80 | 2 | 97.5% |
| 택시 설정 | 41 | 7 | 82.9% |
| AI 대화·기록·설정 | 39 | 1 | 97.4% |
| 나들이 커뮤니티·등록·관심·추천 펼침 | 131 | 13 | 90.1% |
| 내 정보 및 하위 메뉴 | 72 | 0 | 100% |

영역 간 중복까지 제거하면 총 360개 중 337개(93.6%)에 한글이 남지 않았다. 반복 노출을 포함한 나들이 문구는 444개 중 82개가 한글로 남아, 실제 화면에서의 미번역 노출은 고유 문구 비율보다 크다.

## 확인된 차이

1. **나들이 상단 메뉴 3개가 영어에서도 한글이다.** `커뮤니티`, `코스등록`, `관심코스`. `front/public/moov.html`의 `renderOuting()`은 버튼에 `data-i18n-en`을 지정하지만 글자는 내부 span에 있다. `front/public/i18n.js`의 `translateText()`는 텍스트의 직접 부모만 확인하므로 해당 영어 문구를 사용하지 못한다.
2. **나들이의 정렬·추천·카드 안내가 일부 미번역이다.** `취향순`, `거리순`, `최근 7일 —`, `가격·시간 확인 필요`, `참고 예산`, `100,000원 이하`, 사용자 이름이 들어가는 추천 설명, 실제 가격·이동비·영업시간 관련 안내, 전송 대기 기록 안내, 관심 저장 안내가 남는다.
3. **홈 배너 3종은 영어에서도 한글 이미지다.** `front/public/moov-home/js/data.js`의 `image`와 `imageEn`이 동일하다. 음식점·전시·스파이더맨 이미지를 직접 확인했으며 모두 한글이 포함되어 있다. 이미지 밖 제목과 설명은 영어로 전환된다.
4. **렌트 시간 선택의 `최소`, `최대`가 미번역이다.** 샘플의 3시간 요금 `10,180원`은 `₩10,180`으로, 옵션과 총액도 같은 수치로 표시된다.
5. **택시 설정에서 위치·가격 단위·차량 설명 일부가 미번역이다.** `서울 성수동`, `22,000원/시간` 등 시간당 가격 4종, `최대 6인 · 가족·짐이 많은 여행용`, `MOOV 컴팩트 · 약 3분`.
6. **AI 화면에서 언어 전환 직후 날짜가 한글로 남는다.** 샘플은 `9월 21일 (월)`. 날짜는 렌더 시 locale을 사용하므로, 이 결과는 이미 열린 화면에서 언어를 바꾼 경우에 해당한다.
7. **일부 접근성 설명이 한글로 남는다.** AI 설정 버튼의 `루나 전환`, `음성으로 대화하기 전환`, `승차 후 자동 시작 전환`, `대화 기록 저장 전환`, 추천 예산 입력의 `추천 참고 예산`, 이미지의 `무브 캐릭터`, `프로필 사진` 등.

## 일치한 부분과 검사 한계

- 20개 상태 모두 한글로 되돌렸을 때 수집한 텍스트가 원래대로 복구됐다.
- 20개 상태 모두 언어 전환 전후 수집한 버튼·입력 컨트롤의 종류, 동작 식별자, 값이 동일했다. 실제 모든 버튼 기능을 실행했다는 의미는 아니다.
- 확인한 코스 제목·설명과 기본 안내는 대체로 의미가 대응한다. `Saved trips`, `Favorite trips`, `Outing trips` 등 코스 용어는 통일 여지가 있다.
- 전체 모달, 저장 데이터가 있는 모든 상태, 배차 전체 과정, 지도 전체 지명, AI 실제 응답·음성 인식·TTS, 서버 연결 기능은 전수 검사하지 않았다. 영어 문구의 잘림이나 모든 기기 화면 배치도 검증하지 않았다.
- 수정 우선순위: 나들이 메뉴와 새 안내 → 홈 배너 → 렌트 최소·최대 및 택시 문구 → 날짜와 접근성 설명.
