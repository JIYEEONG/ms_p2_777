# 나들이 코스 이름과 이미지

2026-09-22 로컬 API의 공개 코스 1,017개를 확인했다. 이 중 1,000개는 `image_url`이 비어 있었고, `감성 전시 코스`라는 제목만 437개였다. 일부 제목은 실제 장소 태그와도 달랐다. 기존 처리는 사진 없는 코스에 2~5개의 카테고리 사진을 돌려 썼고, 제목에 포함된 카테고리도 사진 선택에 사용했다. 이름 변경만으로는 이미지 반복을 해결할 수 없는 구조였다.

- `outing-data.js`: 반복되는 기본 제목은 실제 방문지 순서로 표시한다. 사용자가 작성한 제목은 유지하되 같은 제목의 서로 다른 경로에는 방문지 이름을 덧붙인다. 동일 ID·동일 경로는 기존처럼 합치며, 반대 방향은 별도 동선으로 유지한다. 저장된 원본 제목이나 코스 ID는 변경하지 않는다.
- `course-media.js`: 고유한 등록 사진을 우선 유지하고, 사진이 없거나 공용 사진을 쓰는 코스에는 장소·활동에 맞는 사진을 배정한다. 카페는 커피·카페 실내, 제과점은 빵, 전시는 전시장, 돼지고기는 바비큐처럼 세부 활동을 구분한다. 실제로 정렬·필터링한 목록에 대해 연속된 50개 카드마다 사진이 겹치지 않도록 배정한다. 선택 가능한 사진이 적은 코스부터 배정하고 사진을 공유하는 인접 코스의 후보를 조정한다. 코스 순서와 추천 점수는 유지하며, 정렬이 달라지면 사진 배정은 달라질 수 있다. 상세보기는 현재 목록의 사진과 일치한다. 사진 로딩 실패 시에도 전체 배정을 다시 계산해 단순 대체로 중복이 생기지 않게 한다.
- `course-photos.js`: 검토한 공개 사진 90장과 작가·출처·이용 조건·파일 해시를 기록한다. 실제 파일은 `assets/course-photos/`에 들어 있어 서비스 실행 시 외부 검색이나 이미지 생성 호출이 필요 없다. 90장 합계 약 14.8 MB이며 브라우저에서는 지연 로딩과 캐시를 사용한다.
- 문화역서울284·DDP·서울숲·석촌호수·홍대·경복궁은 해당 장소 사진으로 연결한다. 일반 활동 사진에는 `분위기 사진`을 표시하며 해당 상호의 실제 매장 사진으로 취급하지 않는다. 이용 조건과 출처는 목록 아래 `사진 정보` 링크에서 모아 볼 수 있다. 별도로 만든 SVG 일러스트는 제거했다.
- 추천 조건·제외 조건·점수 우선순위는 유지한다. 같은 순위에서는 이미 노출한 장소와 덜 겹치는 코스를 먼저 표시한다.

현재 데이터에서는 중복 경로를 제외한 164개 코스에 사진을 표시한다. 공개 사진과 기존 등록·장소 사진을 함께 사용한다. 50개씩 나눈 페이지 단위가 아니라 1–50, 2–51, 3–52처럼 겹치는 모든 구간을 검사한다. 같은 사진은 51번째 카드부터 재사용할 수 있다. 제목만 다른 동일 경로는 기존대로 합친다. 앞으로 특정 활동의 코스가 대량 추가되거나 여러 사진이 동시에 실패해 관련 사진 수가 부족하면, 모든 코스를 유지하고 해당 활동 사진을 가장 오래 사용하지 않은 순서로 배정한다. 이 경우 해당 활동 사진을 보충해야 50개 간격을 유지할 수 있다. 실제 매장 사진을 더 확보하면 해당 코스에 등록해 우선 표시할 수 있다.

현재 데이터의 정렬 4종 × 분류 7종(전체 포함), 총 28개 조합에서 모든 연속 50개 구간의 중복이 없음을 확인했다. 단위 테스트에서는 125개 코스와 50장 사진으로 50/51번째 경계까지 검사하며, 브라우저에서는 실제 사진 로딩·정렬·필터·오류 복구·상세보기 일치를 확인한다.

검증:

```powershell
node --test front/tests/course-presentation.test.cjs front/tests/outing-data.test.cjs front/tests/survey-profile.test.cjs
node tools/check_naver_maps.cjs http://localhost:3000 --course-covers
```

두 번째 명령은 실행 중인 로컬 서버의 공개 코스를 읽고 별도 브라우저 테스트 계정을 사용한다. 실제 계정·코스 데이터는 변경하지 않는다.
