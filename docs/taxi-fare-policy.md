# 택시 요금정책과 계산

사용자가 제공한 `택시_요금정책.xlsx`의 `요금정책_요약` 시트 **‘최종 확정 요금표 (택시)’ A4:D7**을 적용한다. 원본의 손익·자금조달 자료는 웹에 복사하지 않는다. 추출한 요금 파일에는 원본 파일명·SHA-256·시트·셀 위치를 남긴다.

| 요금 구분 | 기본요금 | 기본 포함거리 | 초과거리 1km당 |
| --- | ---: | ---: | ---: |
| 소형 | 3,223원 | 1.6km | 671.5원 |
| 중형 | 4,080원 | 1.6km | 850원 |
| 대형 | 5,950원 | 3km | 1,126.25원 |

`기본요금 + max(0, 전체거리 − 기본 포함거리) × km당 추가요금`

- `택시요금정책_근거!B44`의 3,223.2원은 산정 중간값이다. 앱은 최종 요약표의 **3,223원**을 사용한다.
- 근거 시트의 ‘일반형 요금(주간·평시)’ 범위에 해당한다. 시간요금·심야/혼잡 할증·통행료·예약료는 원본에 계산 규칙이 없어 자동 가산하지 않는다.
- 원본에 반올림 규칙이 없어, **총액을 한 번만 1원 단위로 반올림**하는 구현 규칙을 적용했다. 원 단위 미만이 0.5 이상이면 올린다. 거리요금 단가를 미리 반올림하거나 기존 100원 단위 반올림을 사용하지 않는다.
- 화면의 기본요금·km당 단가·추가요금·총액은 소수점 없이 1원 단위로 반올림하여 표시하고, 아래에 작은 글씨로 안내한다. 별도의 소수점 반올림 차액 행은 표시하지 않는다. 계산에는 원본 단가를 그대로 사용한다.
- 네이버 경로의 실제 정수 미터를 계산에 사용한다. 화면의 km 반올림 값으로 다시 계산하지 않는다. 수동 계산기는 0.001km(1m) 단위 입력을 사용한다.
- 견적의 소요시간은 이동 안내에만 사용한다. 경로 예상시간이나 화면을 켜둔 시간을 실제 주행거리로 간주하지 않는다.
- 앱 차량 매핑: 컴팩트→소형, 이지핏·중형→중형 요금, 라운지→대형 요금. 배리어프리는 이지핏에 통합하며 넓은 출입구·경사로·휠체어 승하차 지원을 안내한다. 패밀리는 **중형(최대 4인)**으로 표시한다.
- 이지핏은 기존 이지핏 요금과 최대 4인 기준을 유지한다. 접근성 기능에 별도 할증을 붙이지 않는다. 저장된 `barrierfree` 선택은 `easyfit`으로 변환하고, `family` ID는 중형 선택을 유지하기 위해 내부 식별자로 남긴다. 이미 저장한 택시 이용 내역의 견적은 다시 계산하지 않는다.
- 렌트 요금은 별도 상품이며 이번 택시 계산에 섞지 않는다.

5.5km 검산: 소형 5,842원, 중형 7,395원, 대형·장애인 차량 8,766원. 중형 7,395원은 원본 `RD회수_시뮬레이션!B44`와 일치한다.

## 파일과 갱신

### 차량별 렌트 정책

| 표시 차종 | 탑승 인원 | 3시간 | 이후 1시간당 | 24시간 |
| --- | --- | ---: | ---: | ---: |
| 컴팩트 | 1~2인 | 10,180원 | 2,200원 | 56,380원 |
| 이지핏 | 최대 4인 | 12,900원 | 2,700원 | 69,600원 |
| 중형 | 최대 4인 | 12,900원 | 2,700원 | 69,600원 |
| 라운지 | 최대 6인 | 29,870원 | 6,300원 | 162,170원 |

렌트는 3~24시간이며 선택 옵션 요금은 별도다. `vehicle-catalog.js`의 차종 설명·인원·렌트 요금을 택시, 렌트, 내 정보의 차량·요금정책에서 함께 사용한다. 원본 엑셀의 요금 단가는 유지하되 앱 차종의 매핑을 변경했다.

- `front/public/vehicle-catalog.js`: 통합 차종, 탑승 인원, 접근성 안내, 렌트 요금.
- `front/public/taxi-fare-policy.js`: 최종 표에서 추출한 데이터와 적용 범위.
- `front/public/taxi-fare.js`: 화면과 검증 코드가 함께 쓰는 요금 계산기.
- `front/public/taxi-fare-ui.js`, `taxi-fare-ui.css`: 차종별 요금, 경로 견적, 수동 계산기, 예약·체험 영수증 화면.
- `tools/import_taxi_policy.py`: Python 표준 라이브러리만으로 엑셀 최종 표를 추출한다. 수식은 실행하지 않고 저장된 값을 읽는다.
- `front/tests/taxi-fare.test.cjs`: 요금 경계·반올림·차종·잘못된 입력 검증.
- `tools/check_taxi_fares.cjs`: 브라우저에서 경로 견적·계산기·예약·종료 흐름 검증.

원본 요금표를 수정한 뒤 Excel에서 저장하고 프로젝트 루트에서 실행한다.

```powershell
.venv/Scripts/python.exe tools/import_taxi_policy.py 'C:\Users\user\Downloads\택시_요금정책.xlsx'
node --test --experimental-test-isolation=none front/tests/taxi-fare.test.cjs
```

실제 차량 주행계와 결제 서비스는 연결되지 않았다. 예약·이용 중·종료에 표시하는 금액은 같은 정책을 적용한 체험용 경로 예상 요금이다. 실제 청구 금액으로 표시하지 않는다.

경로·차종 변경 시 다시 계산하며, 조회 중이거나 실패한 견적으로 예약하지 않는다. 예약 시 검토한 금액·거리·차종·정책 버전을 함께 보관한다. 체험 영수증은 현재 브라우저의 로컬 저장소에 저장하므로 서버 결제 내역이나 다른 기기와 동기화된 기록은 아니다.
