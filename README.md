# MOOV 무인차 플랫폼 앱 프로토타입

`moov_서비스_앱_전체_기획서_V1.0_20260911`과 제공된 IA·콘셉트 화면을 바탕으로 만든 모바일 우선 정적 웹앱 V2.1입니다. Pretendard를 유지하면서 밝은 그린, 18px 카드, 큰 검색 영역과 하단 내비게이션을 중심으로 UI를 재구성했습니다.

## 실행

별도 설치나 빌드가 필요하지 않습니다. `dist/index.html`을 브라우저에서 열거나 정적 웹 서버의 루트로 `dist` 폴더를 지정하세요.

## 구조

- `dist/index.html`: 앱 셸, 로그인, 내비게이션, 아이콘 스프라이트
- `dist/styles.css`: MOOV 그린 디자인 토큰 기반 반응형 UI와 모바일 레이아웃
- `dist/app.js`: 화면 상태, 메뉴 전환, 모달, 택시·렌트·AI·공간·나들이 상호작용
- `dist/assets/`: 제공된 콘셉트 화면 이미지
- `.openai/hosting.json`: 정적 배포 설정

## 구현 범위

- 임의 아이디·비밀번호 로그인(별도 소셜·ChatGPT 인증 없음)
- 5개 하단 메인 메뉴: AI 말동무 / 공간 / 홈 / 나들이 / 내 정보
- 택시·렌트 상호 배타 모드, 상단 이용 모드와 초 단위 실시간 이용시간
- 렌트 2~24시간 설정, 배터리·충전 정책 안내
- 홈 상단 목적지 검색, 경유지 등록, 관심 코스 전체 경로 불러오기
- 음성 우선·텍스트 병행 AI 말동무와 시작·멈춤·중단, 최근 대화 연동
- 차량용 물·과자·목베개·과일·간편식·물티슈 상품 사진과 검색·카테고리 필터
- 숫자 레드닷 장바구니, 결제 후 구매 내역 자동 저장·상세 영수증, 관심 목록
- 코스 둘러보기·AI 추천·직접 입력/이용 기록 기반 내 코스 등록·관심 코스·따라가기
- 장소별 사진 첨부와 회색 이미지 없음 상태, 프로필 사진·이름 편집
- 윈도우·콘텐츠·웰니스·수면·프라이빗 공간 모드와 온도·창문·조명 설정
- 앱 프레임 내부 팝업, 공지·이벤트·이용 기록·관심 코스·결제수단·정책·버전 화면

## 참고

현재 버전은 프론트엔드 프로토타입입니다. 지도, 결제, 차량 관제, OTT, AI 대화 기능은 실제 API 대신 화면 상태와 예시 데이터로 동작합니다.
